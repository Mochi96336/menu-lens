Tri-fold Matrix

折疊單位不是六個分類，而是三個完整紙欄。每個面板始終保留上下兩分類與中間分隔線，折起時 3×2 拓撲仍可辨認。

Mechanism notes

折的是三欄紙面，不是六個分類

兩條摺線

完整 3×2 只有兩條垂直摺線；每片 panel 的上下分類與比例在折疊過程中維持。

中央攤平

焦點 panel 佔約 78vw 並保持平面；左右 panel 依相對位置旋轉 ±58°。

矩陣仍可辨認

折起面板仍顯示水平分類分隔線，不退化成只有分類名稱的窄標籤。

主要風險

CSS 透視能表達摺痕，但沒有真實厚度與遮蔽；若空間關係不可信，仍可能只是裝飾動畫。

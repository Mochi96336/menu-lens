Unfamiliar-reader Study

這是一個 evidence-only runner。它檢查陌生讀者能否在沒有投影順序提示下，使用 25P 與可讀 band labels 完成一個固定的三條件料理任務。

開啟研究工具

Design

六場 2 × 3 反平衡

320px 與 390px 各搭配三種起始投影，形成 S01–S06。Desktop 只作版面與可及性補充，不取代手機 gate。

S01／S04

價格 × 份量，分別在 320px 與 390px。

S02／S05

價格 × 時間，分別在 390px 與 320px。

S03／S06

份量 × 時間，分別在 320px 與 390px。

Single condition

所有場次使用同一個更新後的 25P，不加入教學、篩選、排序或自動投影。

Participant task

共享、價格與時間的交叉判讀

三人共享、每道不超過 NT$500、排除較慢料理；找出完整集合，再回答最快與最低價的取捨。

Technical gate

Runner 不儲存、不上傳、不自動評分

CI 會實際啟動 320px、390px 與 1280px runner，確認 iframe 內有 30 個唯一 Product、三個投影、可讀 band summary、研究 chrome 隱藏、session 完成流程、零 storage、零 cookie，以及 reload 後回到初始狀態。

查看 layout report

Decision gate

只有三種後續分類

25PA ELIGIBLE、25PA STILL BLOCKED 或 STOP 25PA LINE。這個 study object 本身不包含 participant result，也不授權任何 25PA UI。

Consolidation

兩支來源，一個 canonical runner

研究設計、counterbalancing、eligibility gate 與 layout evidence 來自 PR #34；browser execution、reset、storage 與 cookie 邊界由 PR #35 的做法重新接到同一 runner。第二套 participant surface 不再保留。

Menu Lens / research record

手機菜單閱讀研究檔案

保存當時真正做過的畫面，也保存後來再次碰到的相似問題。這裡不把版本排成必然進步史；05、06 保留為回訪，08–24 並列探索不同空間模型，也另外保存產品方向評價。

5 個原始歷史節點 2 次後續回訪 prototype registry 原件與重建分開

How to read

不是進步階梯，而是三條互相靠近的路線

01–04 是有固定 commit 的歷史實作。05、06 是後來回訪舊問題的 prototype；07 記錄常見市場 baseline；08–24 展開不同的空間模型。直接評價另存為產品方向紀錄，不假裝成參與者研究。

Line A

完整菜單閱讀

從完整內容、分類定位與 inline detail 出發，後來回訪密度、欄位對齊與長頁品質。

01 Complete menu → 05 Ledger revisit

Line B

結構、局部與比較投影

從 overview、Anchor 與 shared axis 出發，延伸到 Candidate、comparison，後來再以尺度與分類展開回訪全貌問題。

02 Relational → 03A Candidate marks → 03B Candidate workspace → 04 Comparison → 06 Multi-scale revisit

Line C

空間互動探索

把常見橫向分類分頁記為 baseline，不重建；直接探索分類能否在同一張連續 spread 上保持固定位置並局部展寬。

07 baseline → 08–17 spatial models → 18 / 18A paper references → 19–24 landscape objects → 25 reset → 25P / 25B / 26 depth objects

Object catalog

一個 ID，就是一個研究物件

家族只作標籤，不包住或合併版本。03A、03B、18、18A、25、25P、25B 都各自保留身份、父系、狀態與入口；字母後綴不是同一張卡片的模式。

05 / later reconstruction

Ledger document

unresolved revisit

回訪的問題：在完整菜單不收合的前提下，密度、共享欄位與 inline detail 能把線性閱讀改善到什麼程度？

與早期的關係：沿用 01 的完整長頁與原地細節，但重新處理視覺單位、欄位與捲動質感。

目前不判定：它是 01 的充分 refinement，或只是同一限制的另一種排版。

開啟 05

06 / new prototype

Multi-scale menu map

unresolved revisit

回訪的問題：完整結構能否始終在場，而內容依全店、分類與料理尺度局部展開？

與早期的關係：重新碰到 overview、局部焦點與重新投影，和 02–04 有明顯相似，也改用了分類尺度而非 Anchor／Candidate。

目前不判定：它是否只是舊互動家族的換名版本，或存在可測量的新機制。

Current spatial exploration

07 只標記市場常見的橫向分類導覽；08–21 測試分類欄、長軌道、焦點鏡頭、產品矩陣與紙面形變。22–24 保留為 18 的平面變體；25 否決語意深度前提，26 開始把第三維當成可直接操控的排版空間。

07 / market baseline

Horizontal Menu Atlas

not implemented

熟悉模式：橫向分類導覽，分類內使用垂直料理清單。

目前處理：保留為市場參照，需要正式 baseline 時才使用相同 fixture 重建。

08 / new spatial prototype

Menu Spread

active hypothesis

探索問題：六個分類能否佔據固定位置，聚焦欄原地展寬，而其他欄仍保留為可操作地標？

第一輪邊界：全店 spread、分類 focus、inline product detail；不做自由縮放、Candidate 或下單。

開啟 08

08A / compressed truth cue

Compressed Truth Cue

active 08 variant

單一變因：進入分類 focus 後，壓縮 sibling 繼續顯示 08 renderer 已由真實料理產生的一菜一筆 marks。

保留：08 的固定位置、79vw 聚焦欄、3.15rem 壓縮欄、drag、snap、detail、Escape 與 reset 都不變。

開啟 08A

09 / extreme horizontal prototype

Horizontal Ribbon

active hypothesis

探索問題：若全部料理共用一條水平座標，是否能形成比分類長頁更穩定的整體位置感？

尺度分工：全店尺度看章節與刻度；閱讀尺度看料理；垂直只展開料理資訊。

開啟 09

10 / focus-lens prototype

Fisheye Ribbon

active hypothesis

探索問題：若完整 30 道固定在一個手機寬度，只移動局部放大的閱讀鏡頭，能否減少 09 的長距離移動？

尺度分配：先用分類鏡頭建立局部，再進入料理鏡頭；焦點與鄰近項目逐層取得不同寬度。

開啟 10

11 / matrix prototype

Menu Matrix

active hypothesis

探索問題：固定六列分類與八欄菜序，能否建立比連續橫帶更穩定的二維位置記憶？

列伸縮：聚焦列展高、其他列壓縮保留；料理細節不推動矩陣格位。

開啟 11

12 / paper-space prototype

Paper Menu Field

active hypothesis

探索問題：若矩陣單位改為分類版面，X／Y 只代表紙面位置，縮小的全張菜單是否仍能提供空間記憶？

原地縮放：分類不換位；整張 sheet 依被選分類的原始座標平移與放大。

開啟 12

13 / fixed-sheet lens

Static Loupe

active hypothesis

探索問題：若底圖完全不動，只以可拖曳鏡頭放大同一來源座標，微型紙面能否成為真正的導覽地圖？

代價：放大鏡遮住部分底圖，使用者同時看見內容的縮小與放大版本。

開啟 13

14 / fold topology

Folded Menu

active hypothesis

探索問題：把分類收合表現成連續摺頁，而非介面 accordion，能否讓相鄰關係更容易理解？

機制：一個面板攤平，其他分類沿摺線留下帶角度的窄紙條。

開啟 14

15 / elastic paper

Elastic Paper

active hypothesis

探索問題：若外框固定而內部格線局部拉伸，穩定象限是否足以抵消持續變動的分類邊界？

直接觸控：拖曳焦點穿過紙面；所在欄取得 72%、所在列取得 62%。

開啟 15

16 / weighted elastic paper

Weighted Elastic Paper

active hypothesis

修正問題：八道主餐與兩道甜點不再使用相同聚焦面積；欄、列和焦點都從內容數量計算。

結果：主餐聚焦約佔 45% 紙面，甜點約 17%。

開啟 16

17 / weighted horizontal strip

Weighted Horizontal Strip

active hypothesis

橫向規則：六分類以 8:6:6:4:4:2 共用同一手機寬度，聚焦只放大原有權重。

與 08 不同：沒有固定 79vw 大欄，也沒有任何水平捲動距離。

開啟 17

18 / landscape paper

Landscape Paper

active hypothesis

3×2 紙面：三個紙欄固定等寬，各含上下兩分類；只有欄內列高依料理數配置。

橫向閱讀：整張尺度看全貌，閱讀尺度才攤開紙張並以紙欄 snap。

開啟 18

18A / proportional reference

Proportional Landscape

reference variant

單一變因：18 保持 1:1:1；18A 將三欄依料理總數改為 14:10:6。

參照目的：直接觀察第一欄增加的空間是否值得第三欄被壓窄，不延伸新互動。

開啟 18A

19 / rigid sheet camera

Rigid Horizontal Sheet

reviewed branch

修正誤區：3×2 紙面固定為 840×560，overview 與 reading 只做等比例縮放；橫向手勢只移動 camera。

定位：上方縮圖持續顯示目前可見來源範圍，分類格不重新計算。

開啟 19

20 / tri-fold matrix

Tri-fold Matrix

reviewed branch

折疊單位：三個各含上下兩分類的紙面 panel，而不是六個分類 accordion。

矩陣保留：折起 panel 仍顯示上下分隔線；焦點 panel 攤平、相鄰 panel 旋轉 ±58°。

開啟 20

21 / two-column window

Two-column Reading Window

reviewed branch

兩個狀態：固定三欄紙面只在 A+B 與 B+C 之間移動，一次保留四分類。

共同地標：中間 B 欄在兩個窗口都存在，橫移後仍保留一半可見內容。

開啟 21

22 / weighted focus sheet

Weighted Focus Sheet

18 + 16 variant

18 的骨架：46rem 固定紙面與三個等寬紙欄保持不動。

16 的焦點：選中分類以 1.8× 重配列高，所在紙欄展為 1.65 份，camera 跟著置中；同欄鄰居仍完整。

開啟 22

23 / tracked focus landscape

Tracked Focus Landscape

active 22 extension

折疊差異：沿用 22 的 1.65 欄寬與 camera，但把同欄另一分類收成 2.2rem 標頭。

閱讀焦點：選中分類取得整欄高度，料理字級同步放大；再次點選回到完整 3×2。

開啟 23

24 / vertical landscape

Vertical Landscape

active 18 variant

混合排版：分類標題橫排；菜名與 upright 價格共用同一條直向料理欄，不另起價格排。

內容比例：三欄依料理總數成為 14:10:6；46rem／64rem 紙面都不跟手機寬度連動。

開啟 24

25 / menu dimensions

Menu Dimensions

dimension model reset

第一輪問題：物理隱喻只把平面擠出厚度；保留的 25B 也沒有可辯護的共同 Z 語意。

物件邊界：25 只保存維度模型重置與分支入口，本身不代表 25P 或 25B。

開啟 25

25P / real-axis projection

Menu Projections

active dimensional projection

獨立物件：價格、份量與準備時間形成三張正交投影，30 道料理保持身份連續。

父系：從 25 的維度重置分支，不與 25B 共用畫面或狀態。

開啟 25P

25B / retained falsification

Menu Volume

reviewed stop

獨立物件：完整矩陣沿 Z 軸堆成八層，以共同深度切片閱讀。

保留原因：作為第一輪深度模型的反證，不代表 25P 或 26 的結論。

開啟 25B

26 / parallax layout volume

Parallax Menu Volume

active spatial grammar

第三維的新角色：Z 不對應價格、口味或料理順序，只讓六套分類排版交織在同一個物件裡。

直接操作：斜向拖曳讓分類逐漸成形；雙指張開增加視差，合攏則把目前方向壓成接近平面的可讀版面。

開啟 26

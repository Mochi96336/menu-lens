一份可閱讀、可操作的研究時間線。原始實作直接由當時固定 commit 重建；後來為說明而製作的版本與新假設則另外標示，不再混為一談。

Evidence types

先確認你正在看哪一種證據

原始畫面、後來重建與新方向可以並存，但用途不同。每個原始版本都必須能追溯到 PR、branch、固定 commit 與當時的 build。

Original implementation

從指定歷史 commit 執行原本的 typecheck、test 與 build，再將完整 dist 凍結保存。這是當時真正執行過的畫面。

Interpretive reconstruction

後來為了說明流程或做公平比較而重建。它可以幫助理解，但不能取代歷史原件。

New hypothesis

當時沒有可執行 HTML，後來才提出的新方案。它代表目前研究問題，不代表過去曾經完成。

Timeline

優先開啟「原始實作」複習當時成果；說明性重建留作對照教材，不再冒充原始畫面。

Archive rules

保存規則

原始版本優先

歷史複習先看 frozen original build；重建版只能作為流程說明或比較材料。

階段不互相污染

Prototype C、CND1、CND2 與 CMP1 分別固定在下一階段開始前的完成節點。

來源永久可追溯

originals/manifest.json 與 docs/research-history/original-milestones.tsv 鎖定 PR、commit 與路徑。
